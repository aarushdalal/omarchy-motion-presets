# omarchy-motion-presets 1.1.0

Transactional selector, serialized atomic updates and rollback on rejected compositor reloads; full 19-preset DaemonOS provider, intensity and reduced-motion support.

The refinement preserves existing themes, fonts and desktop identities.
Owned panels use the selected motion style; reduced motion suppresses decorative
translation/scaling. All existing preset names are retained.

Current public files passed the automated privacy scan. Old recordings and
workstation captures were retired from the current tree; existing public history
is preserved. See RELEASE-PRIVACY.md. Public identity, license attribution and
repository links are intentional.

Validation: native Omarchy components compile; Caelestia motion/loader fixtures
passed 114 style/intensity/reduced combinations; both desktop configurations
validate; scoped backend regression tests passed. Actual password/fingerprint
authentication and full login/logout switching require an interactive test.
